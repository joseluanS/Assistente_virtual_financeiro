# 🍎 José: Seu Educador Financeiro

**José** é um assistente virtual desenvolvido para transformar a relação das pessoas com o dinheiro. Diferente de uma simples planilha, o José atua como um mentor que ajuda na organização, categorização e análise crítica de gastos e receitas.

---

## 🚀 Funcionalidades Principais

* **Registro Inteligente:** Entrada simplificada de transações financeiras.
* **Categorização Automática:** Organização de gastos por tipo (Lazer, Essencial, Investimentos).
* **Análise de Saúde Financeira:** Insights baseados nos dados inseridos para ajudar na tomada de decisão.
* **Interface Amigável:** Foco total na experiência do usuário e na clareza das informações.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Persistência de Dados:** JSON / Pandas
* **Interface:** Streamlit 

## 📦 Como Instalar e Rodar

1. **Clone o repositório:**
```bash
git clone https://github.com/joseluanS/Assistente_virtual_financeiro.git

```


2. **Entre na pasta do projeto:**
```bash
cd Assistente_virtual_financeiro

```


3. **Instale as dependências:**
```bash
pip install -r requirements.txt

```


4. **Inicie o José:**
```bash
python main.py

```


## 📝 Estrutura do Projeto

* `main.py`: Ponto de entrada da aplicação.
* `utils/`: Funções auxiliares e cálculos matemáticos.
* `data/`: Local onde as informações financeiras são armazenadas.
